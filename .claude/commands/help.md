Explain how to use SS:

## Commands

| Command | Description |
|---------|-------------|
| `/start` | Start a session — pick up from last time + today's briefing |
| `/stocks` | Current market situation for the stock-pro watchlist |
| `/usage` | Usage stats — session-day count and streaks |
| `/update` | Checkpoint — save progress to state |
| `/status` | Summary of goals, todos, and decisions |
| `/end` | End the session — save log + update state |
| `/help` | This guide |

## Tips

- You can just talk naturally. Tasks and decisions get recorded automatically.
- If there's a task you repeat often, say "make this a command" and a new command will be created under `.claude/commands/`.
- To change your profile or conversation style, ask to edit `profile/me.md`.
